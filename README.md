
# DANA ALTAWEEL — Personal Portfolio

## Project Overview

A responsive personal portfolio built from scratch using HTML5, CSS3,
and JavaScript ES6+.

## Required Sections

- Header and navigation
- About Me with profile photo
- Skills grid
- Project Showcase: Projects 00–03
- Hobbies
- Contact Form
- Footer

## Interactive Features

- Light and dark theme switcher
- Profile photo switcher with a smooth transition
- English and Arabic language switcher
- Dynamic document language and direction (LTR/RTL)
- Contact form demonstration

## Technologies

- HTML5
- CSS3
- JavaScript ES6+
- Git and GitHub

## Directory Structure

```text
ex00/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── profile.jpg
    └── profile-alt.jpg
```

## How to Run

1. Add two images to the `assets` directory.
2. Name them `profile.jpg` and `profile-alt.jpg`.
3. Open `index.html` in your browser.

## Event Lifecycle

User action → Event firing → JavaScript callback → DOM/CSS mutation.

The theme button toggles a CSS class, the photo button updates image
attributes, and the language button updates translated text and document
direction.

## Contact Form

The contact form is a front-end demonstration. It does not send or store
messages.
